# Flux6 Homebrew Tap

[Flux6](https://study-233.github.io/flux6/) for macOS · Apple Silicon · macOS 14+

```sh
brew tap study-233/tap
brew install --cask study-233/tap/flux6
```

The former `freev6` cask is now `flux6`; the rename mapping is included for Homebrew migration. Existing application settings and signing identity are retained.
